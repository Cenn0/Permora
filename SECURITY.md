# Sicherheit melden

Permora ist eine neue, noch nicht produktiv abgenommene Implementierung. Es gibt derzeit keine zugesagte Support-/Patch-SLA und keine Liste produktiv unterstützter Releases.

Sicherheitsprobleme nicht mit echten Tokens, personenbezogenen Daten oder Exploitdetails in öffentliche Issues einstellen. Falls GitHub Private Vulnerability Reporting im Repository aktiviert ist, diesen privaten Kanal verwenden. Ist er nicht aktiviert, zunächst nur um einen privaten Meldeweg bitten; keine persönlichen Kontaktadressen aus Commit-Metadaten übernehmen.

Für einen Bericht hilfreich: betroffener Commit, isolierte Reproduktion, erforderliche Rechte, Auswirkung und erwartetes Verhalten. Tests ausschließlich gegen eigene freigegebene Testsysteme ausführen.

Die offenen Sicherheits-/Betriebsgrenzen stehen in [docs/security.md](docs/security.md), [docs/review.md](docs/review.md) und [docs/roadmap.md](docs/roadmap.md). Ein grüner Utility-Testlauf ist keine Sicherheitsfreigabe.
